2\. REQUISITOS NÃO FUNCIONAIS

| Código | Descrição | Prioridade |
| ----- | :---- | ----- |
| **RNF01** | O sistema deve ser desenvolvido como uma aplicação mobile utilizando Ionic e Angular. | Alta |
| **RNF02** | A interface deve ser responsiva e adequada à utilização em dispositivos móveis. | Alta |
| **RNF03** | A interface deve apresentar navegação simples e intuitiva para os usuários. | Alta |
| **RNF04** | Os diferentes tipos e estados das senhas devem ser apresentados de forma visualmente clara. | Média |
| **RNF05** | As ações realizadas pelo usuário devem apresentar resposta rápida na interface. | Média |
| **RNF06** | A interface deve considerar princípios de acessibilidade. | Alta |
| **RNF07** | O código deve ser organizado em componentes, páginas e demais estruturas adequadas ao projeto. | Média |
| **RNF08** | O código deve ser desenvolvido de forma a facilitar sua manutenção e futuras alterações. | Média |
| **RNF09** | As áreas destinadas ao atendente devem possuir controle de acesso por meio de login. | Alta |
| **RNF10** | O sistema deve impedir, na interface, ações incompatíveis com o estado atual da senha. | Alta |
| **RNF11** | Os dados utilizados para demonstrar o funcionamento do sistema devem ser disponibilizados por meio de dados simulados no frontend. | Alta |
| **RNF12** | A aplicação deve apresentar comportamento consistente durante a navegação entre suas telas. | Média |
