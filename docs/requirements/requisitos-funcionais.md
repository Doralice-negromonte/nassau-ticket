1\. REQUISITOS FUNCIONAIS

| Código | Descrição | Prioridade |
| ----- | :---- | ----- |
| **RF01** | O sistema deve permitir a emissão de uma senha pelo cliente. | Alta |
| **RF02** | O sistema deve permitir a seleção do tipo de senha: SP, SE ou SG. | Alta |
| **RF03** | O sistema deve gerar a numeração da senha conforme o padrão definido. | Alta |
| **RF04** | O sistema deve exibir a senha emitida e suas informações ao cliente. | Alta |
| **RF05** | O sistema deve permitir o acesso do atendente por meio de uma tela de login. | Alta |
| **RF06** | O sistema deve permitir ao atendente chamar a próxima senha da fila. | Alta |
| **RF07** | O sistema deve exibir as senhas chamadas no painel de atendimento. | Alta |
| **RF08** | O sistema deve permitir ao atendente iniciar um atendimento. | Alta |
| **RF09** | O sistema deve permitir ao atendente finalizar um atendimento. | Alta |
| **RF10** | O sistema deve permitir chamar novamente uma senha quando o cliente não comparecer. | Alta |
| **RF11** | O sistema deve representar os diferentes estados de uma senha durante o atendimento. | Alta |
| **RF12** | O sistema deve permitir visualizar informações da fila e dos atendimentos em andamento. | Média |
| **RF13** | O sistema deve disponibilizar uma tela de relatórios com dados dos atendimentos. | Média |
| **RF14** | O sistema deve disponibilizar informações de auditoria dos atendimentos. | Média |
| **RF15** | O sistema deve apresentar mensagens de status para informar o usuário sobre as ações realizadas. | Média |
