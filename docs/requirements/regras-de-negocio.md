3\. Regras de Negócio

| CÓDIGO | DESCRIÇÃO |
| :---- | :---- |
| RN01  | O sistema tem três tipos de senha: SP (prioritária), SE (retirada de exames) e SG (senha geral) |
| RN02  | O sistema segue uma regra de prioridade, definida como: SP → SE/SG → SP → SE/SG   |
| RN03  | Qualquer guichê pode atender qualquer senha  |
| RN04 | Uma senha pode ser chamada novamente caso o cliente não compareça na primeira chamada. |
| RN05  | Se o cliente não comparecer depois de duas chamadas, a senha deve ser considerada abandonada/não compareceu. |
| RN06  | O expediente ocorre das 07:00 as 17:00 |
| RN07  | Se um atendimento já tiver sido iniciado, ele deve ser concluído pelo atendente, mesmo no encerramento do expediente.  |
| RN08  | Ao final do expediente, as senhas que permanecerem na fila devem ser descartadas.  |
| RN09  | A sequência numérica das senhas deve reiniciar a cada dia.  |
| RN10  | O cliente não precisa realizar cadastro ou login.  |
| RN11  | O atendente precisa realizar login para utilizar as funcionalidades de atendimento.  |
| RN12  | O perfil de gestor é responsável pelos cadastros e relatórios |
| RN13  | O painel deve mostrar somente as 5 últimas senhas chamadas. A próxima senha não deve ser exibida antecipadamente.  |
